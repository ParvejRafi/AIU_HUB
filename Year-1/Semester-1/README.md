# 📘 Year 1 - Semester 1

Your first semester! This is where your CS journey begins with programming fundamentals and core concepts.

## 📚 Courses

### [C Programming](./C-Programming/)
**What you'll learn:**
- Basic syntax and data types
- Control structures (if, loops, switch)
- Functions and recursion
- Arrays and strings
- Pointers and memory management
- File I/O

**Key Topics:**
- Variables, operators, expressions
- Control flow
- Functions and scope
- Arrays and pointers
- Structures
- File handling

- Set theory

**Key Topics:**
- Limits and derivatives
- Matrices and vectors
- Mathematical proofs
- Functions and relations

### [Computer Organization & Architecture (COA)](./Computer-Organization-and-Architecture/)
**What you'll learn:**

**Key Topics:**
- Number systems and Boolean algebra

- Processor organization
- Memory management
- I/O organization

### [Sustainability](./Sustainability/)
**What you'll learn:**
- Environmental awareness
- Sustainable practices in technology

- Ethical responsibility

**Key Topics:**
- Environmental impact of technology
- Energy-efficient computing
- E-waste management

## 📝 Study Tips

1. **C Programming** - Practice coding daily, focus on understanding pointers
2. **Mathematics** - Solve problems regularly, understand proofs
3. **COA** - Draw diagrams, visualize hardware components
4. **Sustainability** - Stay updated with current environmental tech trends
