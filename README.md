# 🎓 AIU_HUB

A collection of assignments, projects, and course materials from the **Computer Science** program at **AIU (Albukhary International University)**.

Browse resources organized by **Year** and **Semester** — find what you need quickly!

## 📁 Structure

```
AIU_HUB/
├── Year-1/
│   ├── Semester-1/  (C Programming, Math, Computer Architecture...)
│   ├── Semester-2/  (OOP, Data Communication, Probability...)
│   └── Semester-3/  (Discrete Math, Cyber Ethics)
├── Year-2/
│   ├── Semester-1/  (DSA, DBMS, OS, Software Engineering)
│   ├── Semester-2/  (Cryptography, Cybersecurity, Requirement Engineering...)
│   └── Semester-3/  (Secure Software Dev, Software Testing)

```
